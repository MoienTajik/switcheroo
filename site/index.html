How it works

A proxy that only touches what you asked it to.

Switcheroo sets the macOS system proxy to a tiny local PAC file, so every browser picks it up. No plugins, no config.

  • Mapped URLs are swapped. Cookies, compression and redirects pass through untouched.
  • Everything else is tunneled. HTTPS to unmapped hosts is never decrypted.
  • HTTPS just works. A local CA (mkcert, bundled) your Mac trusts means no certificate warnings.
  • Clean exit. Quitting turns routing off and restores your proxy settings.

Command line

Everything the window does, from your terminal.

The app puts switcheroo on your PATH. Script your rewrites, wire them into dev servers, or run the proxy headless.

  • Same binary. Give it a command and it runs in the terminal instead of opening a window.
  • switcheroo serve runs the proxy with no UI, for scripts and CI.
  • --json output for anything you want to pipe.

FAQ

Questions, answered.

Does this change the website for anyone else?

No. Rewrites happen in a proxy on your Mac. The real site, its DNS, and every other visitor are untouched.

Why does it ask for my password on first launch?

Once, to trust a local certificate authority so rewritten HTTPS pages load without warnings. It's only used for hosts you've added a rewrite for. Everything else is tunneled without decryption.

I still see the old content. What's wrong?

Your browser probably cached it. Hard‑reload with ⌘⇧R. Check DevTools → Network for the x-switcheroo header to confirm a response was swapped.

What's the difference between exact and * rewrites?

https://example.com/app.js matches that one URL. https://example.com/* matches everything under it, and the rest of the path is appended to your target, e.g. http://localhost:3000/.

Does it work on Intel Macs?

Releases target Apple Silicon on macOS 15 or later. You can build from source with Xcode's command‑line tools.

How do I verify a download?

Each release ships a SHA256SUMS.txt and a build‑provenance attestation. Run shasum -a 256 -c SHA256SUMS.txt and gh attestation verify. See the README for the exact commands.
